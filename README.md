# 카드 오토배틀러 (가제)

기획서의 **1:1 경기와 8인 경기**(사전 선택 → 상점과 전투 반복)를 옮긴 규칙 엔진, 봇, 대량 시뮬레이터, 그리고 브라우저 플레이 화면이다.
의존성이 없고 빌드도 없다. Node 20 이상이면 된다.

```
engine/   규칙만 담은 순수 코드 (Node와 브라우저가 같은 파일을 쓴다). field.js는 유닛 소환 전투 시제품
sim/      봇 대 봇 대량 시뮬레이션, 결과는 sim/out/*.csv (git에는 올리지 않는다. 다시 돌리면 똑같이 나온다)
web/      봇과 직접 붙어 보는 플레이 화면 (GitHub Pages에 그대로 올릴 수 있다)
test/     엔진 테스트
tools/    로컬 확인용 정적 서버
```

## 실행

| 하려는 것 | 명령 |
| --- | --- |
| 테스트 | `npm test` |
| 시뮬레이션 전체 | `npm run sim` |
| 판 수를 늘려서 | `node sim/run.mjs --games 10000` |
| 일부 실험만 | `node sim/run.mjs --only cards,pace` |
| 규칙 수치를 바꿔서 | `node sim/run.mjs --rules "{\"commanderHp\":60}"` |
| 플레이 화면 | `npm run web` 후 http://localhost:4173/web/ |
| 한 경기 시뮬레이션 (1:1) | `node sim/match.mjs` |
| 한 경기 시뮬레이션 (8인) | `node sim/match.mjs --mode rank8` |
| 조정: 수치 하나씩 바꿔 보기 | `node sim/tune.mjs --stage sweep` |
| 조정: 조합 탐색 | `node sim/tune.mjs --stage grid --grid "{\"commanderHp\":[45,60],\"unitAtkMult\":[0.5,0.6]}"` |
| 조정: 프리셋 비교 | `node sim/tune.mjs --stage report` |
| 시작 카드 고르기·레벨 보상 재기 | `node sim/opening.mjs` |

`--only`에 쓸 수 있는 이름은 `commanders`, `cards`, `pace`, `rules`다.
바꿀 수 있는 규칙 수치는 [engine/rules.js](engine/rules.js)에 모여 있다.

GitHub Pages에는 저장소 루트를 그대로 올리면 된다. 루트의 `index.html`이 `web/`으로 넘겨 준다.

## 유닛 소환 전투 시제품 (2026-11-16, 브랜치 `field-battle`)

유닛이 칸에 꽂혀서 싸우는 대신, **필드에 소환돼 걸어가고 사거리 안의 적을 치는** 전투를 따로 만들어 봤다.
덱·손패·마나·카드는 그대로고 유닛이 싸우는 방식만 다르다. 결투·난투장·연합전 한 판씩만 되고, 상점·8인 경기·보스에는 아직 연결하지 않았다.

- 엔진: [engine/field.js](engine/field.js), 봇: [engine/fieldbot.js](engine/fieldbot.js)
- 해 보기: `npm run web` 후 http://localhost:4173/web/field.html (기존 화면 위쪽의 "유닛 전투 (실험)")
- 시뮬레이션: `node sim/field.mjs --format all` (`duel`, `melee4`, `alliance` 중 하나만 줄 수도 있다)

### 규칙

| 항목 | 내용 |
| --- | --- |
| 필드 | 칸이 없는 연속 좌표. 결투는 10×12, 연합전은 20×12 직사각형, 난투장은 반지름 10인 원 하나에 넷이 들어간다 |
| 배치 칸 | 칸은 소환할 때만 쓴다. 각자 본진 앞에 가로 5 × 세로 3칸(한 변 2)이 있고, **내 칸에만** 놓을 수 있다 |
| 소환 | 한 사람당 8기까지. 가득 차면 내 유닛 하나를 대체한다 |
| 이동 | 표적 쪽으로 속도만큼 부드럽게 걷고, 사거리 안에 들면 멈춰서 친다. 유닛끼리는 겹치지 않고 서로 밀어낸다 |
| 표적 | 가장 가까운 적. 치고 있던 적이 사거리 안에 있으면 계속 친다. 거리가 같으면 시계 방향으로 가까운 상대 |
| 결투·연합전의 승리 | 상대 지휘관(본진)을 쓰러뜨린다. **지나치기 없음**: 상대 팀 유닛이 하나라도 살아 있으면 본진을 칠 수 없다. 지휘관이 쓰러지면 그 사람의 유닛이 모두 사라진다 |
| 사거리 / 속도 | 근접 1.2~1.7, 견습 궁수·서리 마녀 6, 화염술사 8 / 쥐 떼·그림자 단검 5.5, 흡혈 박쥐 5, 창기병 4.4, 방패병·견습 궁수 3.3, 서리 마녀 3, 화염술사 2.8, 거신 2.2 (초당) |
| 암살 | 원거리 유닛부터 노린다 |
| 수호·집결 | 거리 1.7 안의 아군 기준 |
| 관통 | 표적 뒤쪽 1.4 안의 적에게도 50% |
| 화염술사 필살기 | 표적 주변 반지름 2.2. 범위는 전조 때 정해지므로 그 사이에 벗어나면 맞지 않는다 |
| 거신 필살기 | 자기 주변 반지름 3.2 |
| 후퇴 | 내 유닛을 내 배치 칸으로 옮긴다 |

전열·후열은 **근접·원거리**로 바꿨다: 전투 함성·장군 패시브·성채는 근접 유닛에, 방진·안개는 원거리 유닛에 적용한다. 좁은 협곡은 배치 칸의 양쪽 끝 세로줄을 막는다.

### 난투장: 중앙 점령

난전에서 본진을 부수는 규칙은 맞지 않았다 (세 판 중 두 판이 시간초과, 먼저 찍힌 사람은 일찍 탈락). 그래서 난투장만 승리 조건을 바꿨다. **삼파전은 뺐다.**

| 항목 | 내용 |
| --- | --- |
| 점령 원 | 필드 한가운데, 반지름 3 |
| 점수 | 원 안에 유닛이 **가장 많은 한 사람**만 1초에 1점. 같으면 아무도 못 얻는다 |
| 끝 | 누가 15점에 닿으면 바로 끝. 아니면 40초에 점수순으로 1~4위 (같으면 공동 순위) |
| 본진 | 표적이 아니다. 아무도 중간에 탈락하지 않고, 지휘관 체력은 쓰이지 않는다 |
| 유닛의 움직임 | 거리 4.5 안에 들어온 적만 상대한다. 상대할 적이 없으면 원 안쪽으로 걸어 들어가 버틴다 |
| 원거리 유닛 | 사거리 안이면 멀어도 쏜다. 그래서 원 밖에서 쏘게 되고, 점수에는 보탬이 안 된다 |
| 암살 | 원거리 유닛이면 멀리 있어도 쫓아간다 |

수치(`FIELD_RULES`)는 결투가 30초쯤 되게만 맞췄다: 지휘관 체력 40, 유닛 공격 ×0.5, 유닛 체력 ×1.25. 밸런스는 나중에 본다.

### 같은 순간에 일어난 일에는 순서가 없다

네 사람이 똑같은 덱·똑같은 판단으로 싸우면 전원 동점이 나와야 한다. 이걸 맞추면서 번호가 앞선 자리가 미세하게 유리하던 곳들을 고쳤다.

- 한 틱 안의 공격과 필살기: 그 사이에 체력이 바닥난 유닛도 모두 처리될 때까지는 서 있는 것으로 친다 (수호가 끝까지 피해를 나눠 받는다).
- 같은 틱에 낸 주문: `applyActions`로 함께 처리한다. 앞사람의 주문에 쓰러진 유닛도 뒷사람의 주문을 맞는다.
- 유닛 밀어내기: 모두 같은 순간의 위치를 보고 한꺼번에 옮긴다.
- 거리나 체력이 똑같을 때는 시계 방향으로 가까운 상대가 먼저다 (연쇄 번개, 관통, 봇의 표적 고르기).

### 봇끼리 형식마다 1,000판

| 형식 | 길이 중앙값 | 40초를 채우는 판 | 승자 없음 | 필드 유닛 최대 (평균) | 자리별 승률 |
| --- | --- | --- | --- | --- | --- |
| 결투 | 30.1초 | 17% | 1.0% | 5.7기 | 48.6 / 51.4 |
| 난투장 | 40초 | 59% | 0.4% | 10.1기 | 23.7 / 24.4 / 25.9 / 26.0 |
| 연합전 | 37.6초 | 37% | 5.6% | 10.3기 | 팀 48.9 / 51.1 |

난투장: 15점에 닿아서 끝나는 판 41%, 1위 평균 12.6점, 2위 5.9점, 원 안에 있는 유닛은 평균 2.4기.

- 자리에 따른 유불리는 오차 범위 안이다.
- 난투장은 40초를 채워도 점수로 순위가 갈린다. 예전 규칙(본진 파괴)에서는 승자 없이 끝난 판이 17%였는데 0.4%가 됐다.
- 난투장에서 덱에 있을 때 승률(기대 25%): 쥐 떼 40%, 창기병 32%, 방패병 31%, 흡혈 박쥐 29%, 견습 궁수 28%, 화염술사 23%, 거신 22%, 서리 마녀 21%, 그림자 단검 19%.
- 결투에서 덱에 있을 때 승률: 쥐 떼 54%, 그림자 단검 53%, 방패병 52%, 견습 궁수·서리 마녀 50%, 창기병 49%, 화염술사 48%, 흡혈 박쥐 47%, 거신 44%.

### 남은 문제

- **난투장에서 싼 근접 유닛이 너무 좋다.** 점수를 유닛 "수"로 세기 때문에 쥐 떼가 40%다 (쓰러지면 둘로 갈라져서 더 유리하다). 원거리 위주인 덱은 점수를 못 낸다 (연금술사 9%, 첩보원 12%). 토큰을 반으로 세거나 마나 비용으로 세는 쪽을 봐야 한다.
- **1위가 크게 앞선다.** 1위 12.6점, 2위 5.9점. 봇은 누가 앞서는지 보지 않고 싸운다. 사람이 하면 1위를 함께 견제하겠지만 확인하지 못했다.
- **아직 그렇게 혼잡하지 않다.** 필드에 동시에 있는 유닛은 평균 최대 10기, 원 안에는 평균 2.4기다. 유닛 체력을 2배로 하거나 마나를 1.5배 빨리 줘도 13기쯤까지만 늘었다.
- 상점·드래프트·8인 경기는 여전히 예전(칸) 전투로 돈다. 보스 레이드는 이 방식으로 옮기지 않았다.
- 예전(칸) 전투 엔진에는 삼파전 코드가 남아 있다. 8인 경기 로테이션에서는 더 나오지 않는다.
- 키보드로는 내 배치 칸만 고를 수 있다. 유닛은 마우스로 고른다.

## 키보드 단축키 (웹)

글자 키는 자판의 자리로 읽어서, 한글 입력 상태에서도 그대로 동작한다.

| 화면 | 키 | 하는 일 |
| --- | --- | --- |
| 전투 | `1`~`7` | 손패 카드 고르기 (표적이 필요 없으면 바로 낸다) |
| | `Q` `W` `E` `R` / `A` `S` `D` `F` | 보드 윗줄 / 아랫줄의 칸 1~4. 내 보드는 윗줄이 전열, 상대 보드는 윗줄이 후열 |
| | `Tab` | 표적으로 삼을 상대 보드 바꾸기 (난전·연합전) |
| | `Z` | 다시 뽑기 (누른 뒤 버릴 카드 번호) |
| | `X` `Esc` | 선택 취소 |
| | `Space`, `-` `=` | 일시정지, 느리게·빠르게 |
| 상점 | `1`~`5` | 카드 사기. 보스 보상이 있으면 보상 고르기 (`0`은 받지 않기) |
| | `D` `F` `S` | 리롤, 경험치 구매, 잠금 |
| | `←` `→` | 내 덱에서 카드 고르기 |
| | `G` `X` `V` `C` | 시작 카드 지정, 덱에서 빼기, 융합(몸체 → 재료 고르고 다시 `V`), 3장 합치기 |
| | `Enter` | 전투 시작 |
| 드래프트 | `1`~`3` | 후보 고르기 |
| 결과 창 | `Enter` | 첫 버튼 (다음 라운드 등) |

전투와 상점 화면 오른쪽에도 같은 표가 있고, 전투 중에는 칸마다 글자가 적혀 있다.

- 상점 봇: 저축형·균형형·소비형
- 시작 덱 드래프트: 지휘관 고유 카드 1장 + 3장 중 1장 고르기 7번
- 8인 경기: 형식 로테이션, 난투장(4인 난전), 연합전(2:2), 보스 레이드, 유령 보드, 탈락과 순위 (삼파전은 2026-11-16에 뺐다)

## 아직 없는 것

- 사람끼리의 온라인 대전. 상대는 모두 봇이다.
- 난전 축제, 임대 덱전 같은 일반전 모드와 레이팅
- "덱에서 뺀 카드가 다음 상대 상점에 끼어든다"는 실험 규칙
- 넉백, 전개, 유언, 잔향: 예시 카드 중에 쓰는 카드가 없어서 넣지 않았다. 같은 이유로 전장 "축제"도 뺐다.
- 가시와 집결은 엔진에 있지만, 그 효과를 가진 카드가 없어서 지금 덱에는 나오지 않는다.
- 투자와 포고는 결투 전투에서 효과가 없다. 그래서 상인과 군주는 결투에서 손패 한 장을 손해 본다.

## 기획서에 없어서 정한 것

테스트하면서 바꿔 볼 만한 가정들이다.

| 항목 | 정한 내용 |
| --- | --- |
| 근접과 원거리의 차이 | 근접 유닛은 전열에서만 공격한다. 후열에 놓이면 1초 뒤 빈 전열 칸으로 나온다. |
| 필살기 게이지 | 최대 100. 공격할 때와 맞을 때 차는 양은 유닛마다 다르다 (cards.js의 `ult`). |
| 수호 | 인접한 수호 유닛 하나만 20%를 나눠 받는다. |
| 분열 복제 | 쓰러진 칸과 가장 가까운 빈칸에 나온다. 복제는 다시 분열하지 않는다. |
| 화염술사 십자 범위 | 전조가 시작될 때의 표적 칸이 중심이다. 전조 중에 시전자가 쓰러지면 취소된다. |
| 마나 결정 | 마나 최대치를 넘겨서 쥘 수 있다. |
| 유닛 카드의 행방 | 유닛이 쓰러지면 버린 더미로 간다. 선봉 카드는 그 전투에서 돌아오지 않는다. |
| 강화된 주문·강화·운영 카드 | 효과 수치가 별 하나당 1.5배. |
| 좁은 협곡 | 전열 가운데 2칸(2·3번)만 쓴다. |
| 과열 | 30초 이후 1초가 지날 때마다 공격력 +10%p (40초에 2배). |
| 지휘관 시작 덱 | 기획서의 "시작 덱 성향"을 보고 8장씩 임의로 짰다. |
| 동시 처리 | 같은 틱의 공격은 표적을 먼저 정한 뒤 처리하고, 회복은 그 틱의 공격이 끝난 뒤 들어간다. |

## 시뮬레이션 결과 (2026-11-14, 7만 판)

`sim/out/`에 CSV로 들어 있다. 기획서 수치 그대로 돌렸을 때 눈에 띄는 점은 이렇다.

1. **전투가 약 10초에 끝난다.** 중반 덱 기준 중앙값 10.4초, 90%가 18초 안에 끝난다. 기획서 목표는 30~45초다.
   30초 과열에 닿는 판은 1.4%, 40초를 채우는 판은 0.3%다. 지휘관 체력을 150으로 올려도 중앙값이 23초다.
2. **마나 최대치 성장이 쓰이지 않는다.** 전투가 끝날 때 최대 마나는 평균 4.2다.
   8마나인 거신은 1,265개 덱에서 손으로 낸 판이 7번뿐이고, 사실상 선봉 전용 카드다.
3. **선봉이 승패를 가른다.** 거신이나 2성 창기병이 선봉이면 승률 78%, 1성 견습 궁수·흡혈 박쥐가 선봉이면 15% 안팎이다.
4. **손패 7장은 한 번도 문제가 되지 않는다.** 평균 손패 3.1장, 가득 찬 시간 0.2%. 전투가 짧아서 그렇다.
5. **시작 덱끼리는 장군이 압도한다** (다른 지휘관 상대 88%). 창기병을 선봉으로 세울 수 있어서다.
   다만 시작 덱은 임의로 짠 것이라 덱 구성의 문제일 수 있다.
6. 0번 자리와 1번 자리의 승률은 49.9% 대 50.1%로 자리 편향은 없다.

"냈을 때 승률"은 봇이 그 카드를 어떤 상황에서 내는지에 좌우되므로(정화·교란·연쇄 번개는 주로 밀릴 때 쓴다)
카드의 강약은 "덱에 있을 때 승률"로 보는 편이 낫다.

## 전투 길이 조정 (2026-11-14)

목표는 전투 30~45초다. `sim/tune.mjs`로 찾았고, 후보는 [engine/rules.js](engine/rules.js)의 `PRESETS`에 있다.
웹 설정 화면의 "규칙"에서 골라 직접 해 볼 수 있다. 기획서 기본값(`DEFAULT_RULES`)은 바꾸지 않았다.

### 무엇이 길이를 바꾸는가

- **효과 없음**: 마나 회복 간격, 시작 마나, 뽑기 간격, 손패 장수. 어느 쪽으로 바꿔도 중앙값이 10~11초다.
- **효과 있음**: 지휘관 체력, 유닛 체력, 유닛 공격력, 공격 간격. 다만 30초를 넘기려면 하나만으로는 4배쯤 바꿔야 한다
  (지휘관 체력 250, 또는 유닛 공격 ×0.25).
- **선봉**은 길이에는 영향이 작지만(없애도 12초) 승패에는 가장 크다.

### 후보 비교 (프리셋마다 1,500판)

| | 기획서 기본 | A. 지휘관 250 | B. 공격 ×0.35 · 지휘관 60 | C. 공격 ×0.5 · 체력 ×1.5 · 지휘관 90 | **D. 추천** |
| --- | --- | --- | --- | --- | --- |
| 길이 중앙값 | 10.1초 | 32.0초 | 33.1초 | 33.7초 | **32.3초** |
| 하위 10% | 6.4초 | 22.6초 | 21.0초 | 22.1초 | 18.7초 |
| 40초를 채운 판 | 0.5% | 19.6% | 24.4% | 25.7% | 24.9% |
| 가장 비싼 유닛이 더 비싼 쪽의 승률 | 80.9% | 80.8% | 81.9% | 82.8% | **58.1%** |
| 10초에 우세한 쪽이 이길 확률 | 93.7% | 95.3% | 88.2% | 88.4% | **81.5%** |
| 같은 덱에서 판단 봇이 무작위 봇을 이길 확률 | 61.8% | 64.5% | 64.8% | 69.4% | **74.4%** |
| 카드별 승률의 폭 | 37.9%p | 38.4%p | 37.5%p | 39.3%p | **21.2%p** |
| 지휘관별 승률의 폭 | 23.8%p | 24.7%p | 23.4%p | 20.5%p | 19.2%p |

**D. 추천** = 유닛 공격 ×0.5, 유닛 체력 ×1.5, 지휘관 체력 60, 선봉은 3마나 이하 유닛만.

- A는 숫자 하나만 바꾸면 되지만, 10초에 이미 95%가 결판난 뒤 20초 동안 지휘관 체력만 깎는 전투가 된다.
- B와 C는 유닛끼리의 싸움 자체가 느려져서 초반 우세가 덜 굳지만, 비싼 선봉이 이기는 구도는 그대로다.
- D는 선봉 비용을 묶어서 그 구도를 푼다. 거신의 덱 승률이 79%에서 47%로 내려가고, 실력(봇 판단)이 결과에 더 반영된다.

### D에서 새로 보이는 것

- **군주가 약하다** (37.7%). 결투에서 포고가 죽은 카드인 데다 시작 덱의 영향으로 보인다. 그다음은 첩보원 56.9%, 장군 55.5%.
- **큰 카드는 여전히 잘 안 나온다.** 5마나 이상 카드를 내는 횟수가 판당 0.35회다. 마나 최대치가 40초에야 8이 되기 때문이다.
  최대치를 5초마다 +1로 바꾸면 끝날 때 최대 마나가 6.8에서 7.9로 오르지만 내는 횟수는 0.42회로 조금만 는다.
- **뽑기 3초, 손패 7장, 마나 1.5초는 그대로 둬도 된다.** 평균 손패 3.5장, 손패가 가득 찬 시간 3.1%, 마나가 가득 찬 시간 11%다.
  손패를 5장으로 줄이면 가득 찬 시간이 20%로 뛰고, 뽑기를 2.5초로 당기면 7%가 된다.
- **과열은 제 역할을 한다.** 없애면 40초를 채우는 판이 25%에서 34%로 는다.
- 40초를 채워 체력 비율로 판정하는 판이 4판 중 1판이다. 많다고 느껴지면 지휘관 체력을 더 낮춰 볼 수 있는데, 그 값은 아직 돌려 보지 않았다.

## 시작 덱 드래프트 (2026-11-15)

시작 덱이 지휘관을 따라가지 않는다. 지휘관은 **패시브와 고유 카드 1장**만 주고, 나머지 7장은 경기를 시작할 때 드래프트로 고른다.

- 3장 중 1장 고르기를 7번 한다. 고유 카드와 합쳐 8장으로 1라운드를 시작한다.
- 후보 3장 중 **첫 장은 내 픽 카드에서**, 나머지 두 장은 공용 풀(중립 카드 + 모두의 픽 카드) 전체에서 뜬다. 상점의 시그니처 칸과 같은 방식이다.
- 후보의 등급은 1등급 60%, 2등급 30%, 3등급 10%다. 4등급 이상은 뜨지 않는다.
- 고른 카드는 풀에서 빠진다. 그래서 나중에 덱에서 빼면 풀로 돌아간다.
- 지휘관별 정해진 시작 덱은 "전투 한 판" 모드와 `createGame({ startDecks: 'commander' })`에만 남아 있다.

기획서에 없어서 정한 것: 고르는 횟수(7번), 후보 수(3장), 등급 확률, 고유 카드를 드래프트와 별도로 주는 것.
수치는 [engine/game.js](engine/game.js)의 `draftPicks`, `draftOptions`, `draftOdds`다.

- **지휘관 격차가 크게 줄었다.** 앞서 본 격차의 대부분은 지휘관 능력이 아니라 정해진 시작 덱에서 나온 것이었다.

- 아래 "8인 경기"와 "상점과 한 경기"의 결과 표는 드래프트를 넣기 전에 잰 숫자다.

### 카드 빼기

골드로 덱의 카드를 빼는 기능은 상점에 있다 (2골드, 라운드당 1번, 덱 최소 8장).
웹에서는 상점의 "카드 빼기" 버튼을 누른 뒤 뺄 카드를 누르면 된다. 덱의 카드를 먼저 누르고 "덱에서 빼기"를 눌러도 된다.

## 상점과 한 경기 (2026-11-15)

[engine/game.js](engine/game.js)가 상점·경제·라운드 진행을, [engine/shopbot.js](engine/shopbot.js)가 상점 봇을 맡는다.
웹의 "한 경기" 탭에서 봇과 처음부터 끝까지 해 볼 수 있다. 전투 규칙은 프리셋 `cards`(선봉 없음)다.

### 한 경기의 흐름

1. **사전 선택**: 지휘관 1명과 픽 카드 8종 (5등급은 1종까지). 그다음 시작 덱 7장을 드래프트로 고른다.
2. **상점**: 5칸 중 1칸은 시그니처 칸이라 내 픽에서만 뜬다 (첩보원은 2칸). 다음 전투의 형식과 전장이 미리 보인다.
3. **전투**: 1~2라운드는 중립 몬스터와 연습(HP 피해 없음, 이기면 골드 +2), 3라운드부터 결투.
4. **결과**: 패자는 기본 피해(2에서 8까지 오름) + 승자 보드에 남은 유닛 수만큼 HP를 잃는다. HP 40이 0이 되면 끝.

### 기획서 그대로인 것

| 항목 | 값 |
| --- | --- |
| 수입 | 기본 5, 이자 10골드당 1(최대 3), 연승·연패 2회 +1 / 4회 +2 |
| 지출 | 카드 가격 = 등급, 리롤 2, 잠금 무료, 카드 빼기 2(라운드당 1번), 경험치 4골드에 4 |
| 덱 | 최소 8장, 최대 30장 |
| 등급 확률 | 상점 레벨 3~8 표 그대로 |
| 풀 장수 | 등급별 12/10/8/6/4장, 고른 사람 한 명당 +50% |
| 강화 | 같은 카드 3장 → 2성, 2성 3장 → 3성. 합칠지는 선택 |
| 융합 | 경기당 3회(연금술사 5회), 한 카드에 효과 1개, 융합 카드를 빼면 두 카드 모두 풀로 |
| 지휘관 | 상인(골드 +1, 첫 리롤 무료), 연금술사(융합 5회), 첩보원(시그니처 칸 2개), 투자(이기면 골드 +3) |

### 기획서에 없어서 정한 것

| 항목 | 정한 내용 |
| --- | --- |
| 레벨 보상 | 선봉 칸(1·1·2·2·3·3) 대신 **고르는 시작 카드 장수**가 1·1·2·2·3·3으로 는다. |
| 레벨업 경험치 | 3→4는 6, 4→5는 10, 5→6은 16, 6→7은 24, 7→8은 36. 라운드마다 +2. |
| 기본 피해 | 결투 두 판마다 +1 (3·4라운드 2, 5·6라운드 3, … 15라운드부터 8). |
| 무승부 | 양쪽이 기본 피해의 절반(올림)을 받는다. |
| 중립 카드 | 기획서의 "기본 중립 카드 20종"이 따로 없어서, 지금 있는 카드 22종 전체가 풀에 들어간다. |
| 시작 덱 카드 | 풀에서 온 카드가 아니라서, 빼도 풀로 돌아가지 않는다. |
| 품절 | 상점에 뜬 카드라도 풀에 남은 장수가 0이면 살 수 없다. |
| 잠금 | 한 라운드만 유지되고 풀린다. |
| 강화·융합과 덱 최소 | 합친 뒤 덱이 8장 밑으로 내려가면 할 수 없다. |
| 연습 라운드 | 중립 몬스터는 싼 유닛 8장을 느리게 내는 봇이다 (이길 확률 약 99%). 연승·연패에는 넣지 않는다. |
| 웹의 상점 시간 | 기본은 제한 없음. 30초(기획서)와 60초를 고를 수 있다. |

### 봇끼리 돌려 본 결과 (드래프트 도입 전, 1:1, `node sim/match.mjs --games 500`)

밸런스는 아직 손대지 않았고, 시스템이 돌아가는지만 본 숫자다.

| 항목 | 값 |
| --- | --- |
| 경기 길이 | 중앙값 8라운드, 약 8.1분 (상점 30초로 계산). 90%가 11라운드 안에 끝난다. 기획서 목표는 10~15분. |
| 끝날 때 | 상점 레벨 5.3, 덱 12.9장, 강화된 카드 6.8장, 융합 카드 0.6장 |
| 경기당 행동 | 리롤 2.9번, 경험치 구매 3.2번, 카드 빼기 0.6번 |
| 승자의 남은 HP | 28.6 / 40 |
| 역전승 (HP가 10 이상 뒤졌다가 이김) | 17.8% |

나중에 밸런스를 볼 때 먼저 볼 것들이다.

- **지휘관 격차가 크다.** 상인 79%, 연금술사 69%, 첩보원 51%, 장군 30%, 군주 22%. 전투만 돌렸을 때와 순서가 뒤집혔다.
  상점이 생기면서 상인의 골드가 값을 하고, 시작 덱에 싼 카드가 겹치는 쪽이 강화를 빨리 한다.
- **한쪽으로 기운다.** 승자가 HP를 평균 29 남긴다. 피해에서 "남은 유닛 수"가 기본 피해보다 커서 연패하면 다섯 판쯤에 끝난다.
- **강화가 빠르다.** 8라운드쯤에 덱의 절반이 2성이다.
- **융합을 거의 안 쓴다** (봇 기준 경기당 0.6장). 봇이 서툰 탓이 크다.
- 상점 봇의 카드 가치 점수는 임시값이다.

## 선봉 없이 카드 위주로 (2026-11-15)

방향: 선봉을 없애고, 전투 전 판단은 **시작 카드 고르기**로 옮긴다. 프리셋 `cards`(E)가 이 규칙이고 웹의 기본값이다.

- **선봉 없음.** 보드는 비어서 시작한다.
- **시작 카드 고르기.** 시작 손패 4장 중 N장을 덱에서 직접 고른다. 추가로 받는 게 아니고, 마나도 그대로 내야 한다.
- 길이는 유닛 공격 ×0.5, 유닛 체력 ×1.25, 지휘관 체력 60으로 맞췄다 (중앙값 32초, 40초를 채우는 판 19%).

`node sim/opening.mjs`로 잰 결과다 (조건마다 1,500판).

### 몇 장을 고르게 할까

0장부터 4장까지 바꿔도 전투 길이(31.5~32초), 가장 비싼 유닛을 가진 쪽의 승률(54~58%),
10초에 우세한 쪽이 이길 확률(77~82%)이 거의 그대로다. 고르는 장수를 늘려도 예전 선봉 같은 쏠림이 생기지 않는다.

### 무엇을 고르느냐가 승패에 반영되는가

같은 덱을 쥐고, 한쪽은 정해진 방식으로 고르고 상대는 무작위로 골랐을 때의 승률이다.

| 고르는 방식 | 1장 | 2장 | 3장 |
| --- | --- | --- | --- |
| 3마나 안에서 가장 센 유닛 | 57.3% | 63.9% | 65.8% |
| 싼 유닛부터 | 55.4% | 63.0% | 67.2% |
| 1·2·3마나 유닛 하나씩 | 55.4% | 64.0% | 68.0% |
| 가장 센 유닛 (비용 무시) | 51.9% | 53.5% | 56.4% |
| 운영 카드부터 | 51.9% | 55.5% | 56.4% |

- 잘 고르면 2장 기준으로 64%를 이긴다. 전투 전 판단으로서 무게가 충분하다.
- "제일 센 카드를 고른다"는 답이 아니다. 초반에 바로 낼 수 있는 유닛을 고르는 쪽이 낫다.
- 다만 지금 봇 기준으로는 "싼 유닛 위주"가 거의 정답이라, 판단의 깊이는 얕다.
  상대 덱이나 전장을 보고 고를 이유가 생기려면 카드 쪽에서 상성이 더 뚜렷해야 한다.

### 상점 레벨 보상으로 무엇이 적당한가

같은 덱에서 한쪽만 보상을 받았을 때 그쪽의 승률이다. 레벨이 한 단계 앞선 쪽이 얼마나 유리한지로 읽으면 된다.

| 한쪽만 받는 보상 | 승률 |
| --- | --- |
| 고르는 시작 카드 +1장 / +2장 | 55.5% / 59.6% |
| 마나 최대치 +1 / +2 | 59.2% / 62.0% |
| 시작 손패 +1장 / +2장 | 64.9% / 73.1% |
| 시작 마나 +1 / +2 | 73.3% / 82.3% |
| (참고) 무료 선봉 1칸, 3마나 이하 | 79.2% |
| (참고) 무료 선봉 1칸, 제한 없음 | 93.7% |

- **시작 마나는 너무 세다.** 1만 더 받아도 73%다.
- **고르는 시작 카드 장수**(레벨에 따라 1→2→3장)와 **마나 최대치 +1**이 완만하다. 선봉 칸 1→2→3을 그대로 대신하기도 쉽다.
- 무료 선봉 한 칸은 94%짜리 보상이었다. 선봉을 뺀 판단과 맞는 결과다.

### 이 규칙에서 남는 문제

- **장군이 가장 세다** (59~61%). 전열 체력 +10%가 느려진 전투에서 더 오래 값을 한다.
- **군주가 가장 약하다** (약 35%). 포고가 결투에서 죽은 카드다.
- **첩보원은 약하지 않다.** 시작 카드를 고르지 않으면 49%, 2장 고르면 57.6%로 장군(58.9%) 바로 다음이다.
  3마나 그림자 단검을 시작 손패에 확정할 수 있어서로 보인다.
  선봉을 미리 보는 패시브는 쓸모가 없어져서 **"상대가 고른 시작 카드를 미리 본다"로 바꿨다.**
  웹에서는 첩보원을 고르면 설정 화면과 전투 기록에 상대의 시작 카드가 보인다. 봇은 이 정보를 아직 쓰지 않는다.
- **밸런스는 나중에 본다.** 상점·경제 같은 나머지 시스템을 먼저 만든 뒤에 다시 잰다. 위 문제들은 그때까지 그대로 둔다.
- **큰 카드는 여전히 잘 안 나온다** (5마나 이상 판당 0.28회).

### 한계

- 봇이 단순해서, 사람이 하면 달라질 수 있는 부분(방진 타이밍, 후퇴, 대체 판단)은 과소평가된다.
- 중반 덱은 상점을 흉내 낸 무작위 덱이다. 상점·경제가 들어오면 선봉과 큰 카드의 값이 다시 달라진다.
- 유닛 공격을 줄이면 주문 피해(화염탄 6, 연쇄 번개 10/7/5)는 상대적으로 세지고, 유닛 체력을 늘리면 약해진다.
  D는 둘을 섞어 그 차이를 줄였지만 주문 수치는 따로 손보지 않았다.
