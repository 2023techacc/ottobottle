# 카드 오토배틀러 (가제)

기획서의 **1:1 경기와 8인 경기**(사전 선택 → 상점과 전투 반복)를 옮긴 규칙 엔진, 봇, 대량 시뮬레이터, 그리고 브라우저 플레이 화면이다.
전투는 **유닛 소환 전투**다: 덱·손패·마나로 카드를 내면 유닛이 필드에 소환돼 걸어가서 사거리 안의 적을 친다.
의존성이 없고 빌드도 없다. Node 20 이상이면 된다.

```
engine/   규칙만 담은 순수 코드 (Node와 브라우저가 같은 파일을 쓴다)
            field.js 전투, fieldbot.js 전투 봇, game.js 상점·경기, shopbot.js 상점 봇, personas.js 봇 성격, ranked.js 랭크전, cards.js 카드 데이터
sim/      봇 대 봇 대량 시뮬레이션, 결과는 sim/out/*.csv (git에는 올리지 않는다. 다시 돌리면 똑같이 나온다)
web/      봇과 직접 붙어 보는 플레이 화면 (GitHub Pages에 그대로 올릴 수 있다)
test/     엔진 테스트
tools/    로컬 확인용 정적 서버
```

## 실행

| 하려는 것 | 명령 |
| --- | --- |
| 테스트 | `npm test` |
| 플레이 화면 | `npm run web` 후 http://localhost:4173/web/ ("한 경기"와 "전투 한 판") |
| 형식별 전투 비교 (결투·난투장·연합전) | `npm run sim` (= `node sim/field.mjs --format all`) |
| 한 형식만 | `node sim/field.mjs --format melee4 --games 4000` |
| 대난투 | `node sim/field.mjs --format ffa --players 8 --games 200` (한 판에 1초쯤) |
| 카드 넣어 보기 | `node sim/fieldswap.mjs` |
| 봇이 카드를 제대로 쓰는지 | `node sim/botcheck.mjs` (카드마다 낸 비율·다시 뽑기로 버린 비율·끝까지 손에 남은 비율) |
| 봇 난이도끼리 | `node sim/botlevels.mjs` (리그전과 결투 레이팅), `node sim/match.mjs --mode rank8 --levels` (경기에서 난이도별 순위) |
| 첩보원 봇의 정보 쓰기 | 기본은 빠른 대응. `node sim/match.mjs --spy-info on`은 미리 돌려 보기(6~7배 느리다), `off`는 안 쓴다 |
| 봇 성격별 성적 | `node sim/match.mjs --personas` (플레이어마다 성격을 무작위로. 지휘관·상점 성향도 성격을 따른다) |
| 랭크전 시즌 | `node sim/ranked.mjs` (8인, 봇 160명 × 25경기), `node sim/ranked.mjs --mode duel` (봇 200명 × 40경기). 티어 분포 |
| 랭크전에서 성향별 레이팅 | `node sim/ranked.mjs --level normal` (모두 같은 실력으로 두고 성격·지휘관·상점 성향별로 잰다), `--personas none --commanders main` (주력 지휘관별), `--personas rusher,big` (성격 고르기) |
| 한 경기 (1:1 / 8인) | `node sim/match.mjs` / `node sim/match.mjs --mode rank8` |
| 규칙 수치를 바꿔서 | `node sim/field.mjs --rules "{\"commanderHp\":30}"`, `node sim/match.mjs --econ "{\"playerHp\":60}"` |

전투 수치는 [engine/rules.js](engine/rules.js)의 `DEFAULT_RULES`(마나·뽑기 등 공통) 위에 [engine/field.js](engine/field.js)의 `FIELD_RULES`를 덮어쓴다. 경제 수치는 [engine/game.js](engine/game.js)의 `DEFAULT_ECON` 위에 모드별 값(`MODES`)을 덮어쓴다.

GitHub Pages에는 저장소 루트를 그대로 올리면 된다. 루트의 `index.html`이 `web/`으로 넘겨 준다.

## 전투

### 기본 규칙

| 항목 | 내용 |
| --- | --- |
| 자원 | 마나 3에서 시작, 1.5초마다 1, 최대치는 8초마다 +1 (8까지). 손패 4장으로 시작, 3초마다 1장, 7장까지. 다시 뽑기는 마나 1, 쿨다운 4초 |
| 필드 | 칸이 없는 연속 좌표. 배치 칸 한 변이 2 |
| 배치 칸 | 칸은 소환할 때만 쓴다. 각자 본진 앞에 가로 5 × 세로 3칸이 있고, **내 칸에만** 놓을 수 있다 |
| 소환 | 한 사람당 8기까지. 가득 차면 내 유닛 하나를 대체한다 |
| 이동 | 표적 쪽으로 속도만큼 부드럽게 걷고, 사거리 안에 들면 멈춰서 친다. 유닛끼리는 겹치지 않고 서로 밀어낸다 |
| 표적 | 가장 가까운 적. 치고 있던 적이 사거리 안에 있으면 계속 친다. 거리가 같으면 시계 방향으로 가까운 상대 |
| 본진 | **지나치기 없음**: 상대 팀 유닛이 하나라도 살아 있으면 본진을 칠 수 없다 (대난투만 다르다). 지휘관이 쓰러지면 그 사람의 유닛이 모두 사라진다 |
| 시간 | 40초. 30초부터 1초마다 공격 +10% (과열). 시간이 다 되면 지휘관 체력 비율로 판정 |
| 수치 | 지휘관 체력 40, 유닛 공격 ×0.5, 유닛 체력 ×1.25 (결투가 30초쯤 되게만 맞췄다) |

전열·후열 대신 **근접·원거리**로 나눈다: 전투 함성·방진·장군 패시브·성채는 근접 유닛에, 안개는 원거리 유닛에 적용한다. 좁은 협곡은 배치 칸의 양쪽 끝 세로줄을 막는다.

### 형식

| 형식 | 인원 | 필드 | 이기는 법 |
| --- | --- | --- | --- |
| 결투 | 2 | 10×12 | 상대 본진을 부순다 |
| 연합전 | 4 (2:2) | 20×12 | 상대 팀 본진 둘을 모두 부순다 |
| 난투장 | 4 | 반지름 10인 원 | **중앙 점령**: 점수로 순위 (아래) |
| 보스 레이드 | 1 + 보스 | 10×12 | 40초 동안 보스에게 준 피해 |
| 대난투 | 3~12 | 반지름 "4 + 인원 × 1.7"인 원 | 마지막까지 지휘관이 남는다 (아래) |

**난투장**은 본진을 치지 않는다. 한가운데 반지름 3인 원 안에 유닛이 **가장 많은 한 사람**만 1초에 1점(같으면 아무도 못 얻는다), 적 유닛을 쓰러뜨리면 1점(**원 안에서면 2점**, 작은 복제는 절반, 같은 순간에 함께 쓰러뜨리면 나눠 갖는다).
20점에 먼저 닿으면 바로 끝나고, 아니면 40초에 점수순으로 1~4위. 유닛은 거리 4.5 안의 적만 상대하고, 상대할 적이 없으면 원 안쪽으로 들어가 버틴다.

**보스 레이드**: 고대 골렘은 위쪽 가운데에 서 있고 움직이지도 밀리지도 않는다. 쓰러지지 않고, 10초마다 전조 1.5초 뒤 자기 주변(반지름 3.8)을 친다. 지휘관은 피해를 받지 않는다.

### 대난투 (2026-11-17)

여럿이 한 필드에서 그냥 싸우는 모드다. "전투 한 판"에서 3~12명으로 해 볼 수 있다 (8인 경기 로테이션에는 넣지 않았다).

| 항목 | 내용 (`FFA_RULES`) |
| --- | --- |
| 필드 | 반지름 4 + 인원 × 1.7 (8명이면 17.6). 이웃의 배치 칸끼리 겹치지 않는 가장 작은 크기 |
| **분대** | 유닛 카드 한 장에 같은 유닛이 **3기** 나온다. 카드는 한 장만 버린 더미로 돌아간다. 한 사람당 16기까지 |
| 자원 | 시작 마나 5, 1초마다 마나 1, 1.5초마다 1장 |
| 유닛 체력 | ×2.5 (다른 형식은 ×1.25) |
| 본진 | 가까이(4 안) 있는 자기 유닛만 지킨다. 싸우러 나간 사이에 털릴 수 있고, 본진이 받는 피해는 ×2 |
| 시간 | 75초 (과열은 55초부터). 순위는 먼저 쓰러진 순서, 시간이 다 되면 지휘관 체력 비율 |

**왜 이렇게 됐나** (8명, 봇끼리 24~120판씩). 처음에는 다른 형식과 같은 규칙으로 돌렸는데 혼잡하지 않았다.

| 바꾼 것 | 필드 유닛 평균 / 최대 | 탈락 인원 | 한 명만 남은 판 |
| --- | --- | --- | --- |
| 다른 형식과 같은 규칙 | 12.6 / 19 | 1.9 | 0% |
| 유닛 체력 ×2.5, 마나 1초, 뽑기 1.5초, 본진 지키는 범위 6 | 21.4 / 30 | 2.1 | 0% |
| 뽑기 1초, 체력 ×4, 마나 0.7초 | 27.4 / 36 | 1.2 | 0% |
| **위 + 분대 3기, 16기까지** | **54 / 83** | 2.9 | 4% |
| **+ 본진 지키는 범위 6 → 4, 본진 피해 ×2, 75초 (지금)** | **45 / 78** | **5.4** | **18%** |

- 카드가 들어오는 속도를 올려도 유닛이 죽는 속도가 비슷하게 따라 올라서, 한 사람이 동시에 세우는 유닛은 3~4기에서 잘 안 늘었다. **분대 소환**이 가장 크게 들었다.
- 처음 규칙(지나치기 없음)에서는 유닛이 하나라도 있으면 본진을 못 쳐서 아무도 탈락하지 않았다.
- 싸움은 가운데가 아니라 이웃끼리 둘레를 따라 벌어진다. 자리별 승률은 오차 범위 안이다 (9.0~15.6%, 기대 12.5%, 오차 ±6).
- 시간이 다 돼서 끝나는 판이 82%고, 그중 절반쯤은 지휘관 체력이 꽉 찬 사람이 둘 이상이라 1위가 공동이다.

### 같은 순간에 일어난 일에는 순서가 없다

네 사람이 똑같은 덱·똑같은 판단으로 싸우면 전원 동점이 나와야 한다 (테스트로 확인한다).

- 한 틱 안의 공격·필살기·유언 폭발: 그 사이에 체력이 바닥난 유닛도 모두 처리될 때까지는 서 있는 것으로 친다.
- 같은 틱에 낸 주문은 `applyActions`로 함께 처리한다.
- 유닛 밀어내기와 넉백은 모두 같은 순간의 위치를 보고 한꺼번에 옮긴다.
- 거리나 체력이 똑같을 때는 시계 방향으로 가까운 상대가 먼저다.

| 군주 | 받는 HP 피해 −25% (1:1은 −40%) |

### 밸런스 조정 (2026-11-18)

**재는 법**

- 카드: `node sim/fieldswap.mjs`. 무작위 중반 덱끼리 붙이되 한 자리의 덱에서만 카드 2장을 빼고 그 카드 2장을 넣는다. 지휘관 시작 덱과 섞이지 않는다. 빼는 카드에 강화·융합된 카드가 섞여서 전체가 100보다 조금 낮게 나온다. 정찰(아무것도 안 하고 2장 뽑기)이 기준선 노릇을 한다 (95~107).
- 지휘관: `node sim/match.mjs`로 실제 경기를 돌린다 (8인 400경기, 1:1 1,000경기). 패시브 대부분이 경기에서만 효과가 있어서, 전투 한 판으로는 재지 않는다.

**무엇이 문제였나**

- 몸(유닛)이 압도적이었다. 결투·연합전은 유닛이 하나라도 살아 있으면 본진을 못 치니 몸을 많이 까는 쪽이 이긴다. 1마나 방패병이 체력 17.5(배율 포함)에 수호까지 있어서 지수 113~138이었다.
- 주문은 거의 다 55~80이었다. 유닛에는 체력 ×1.25가 붙는데 갑옷·회복 같은 주문 수치에는 배율이 없어서, 3마나 갑옷(체력 +12)이 1마나 방패병보다 못했다.
- 비싼 유닛(화염술사 70, 거신 66)도 약했다. 최대 마나가 오르는 속도를 바꿔 봐도(8초 → 5초) 지수가 거의 그대로여서 원인은 마나가 아니라 카드 수치였다.
- 효과가 없던 카드: 방진(범위 피해 감소인데 막을 범위 공격이 드물다), 교란(침묵 2초), 포고(쫓아가느라 진형이 무너져서 내면 오히려 손해).
- 상점 봇이 융합을 거의 안 해서(한 명이 한 경기에 0.23장) 연금술사가 경기에서 가장 약했다. 융합 조건을 넓히자 2.4장이 됐고 연금술사가 너무 세져서 융합 횟수를 다른 지휘관과 같게 3회로 줄였다.
- 상인의 "라운드 첫 리롤 무료"가 골드 +1보다 훨씬 컸다 (1:1 승률 63%). 빼고 골드 +2로 바꿨다.
- 군주의 패시브는 난전에만 들어서 1:1에서 아무 효과가 없었다 (1:1 승률 33~40%). 모든 형식으로 넓히되, 8인은 HP 피해가 커서 감소 폭을 다르게 했다.
- 첩보원의 패시브(상대 시작 카드 보기)는 봇이 못 쓴다. 전투 시작 손패·마나 +1을 더했다.

**바꾼 것**: 방패병 체력 14→9, 가시 거북 22→16, 그림자 단검 9→12, 흡혈 박쥐 8→10, 견습 궁수 6→8, 서리 마녀 공 3→4·체 10→14, 창기병 공 6→7·체 18→22, 망치 기사 공 5→6·체 20→28, 화염술사 5→4마나·공 4→5·체 16→20·필살기 20→28, 거신 8→6마나·체 60→70. 주문은 위 표처럼 수치를 올리거나 마나를 내렸다. 방진·교란·포고·비축은 효과를 새로 만들었다 (침묵은 쓰는 카드가 없어져서 엔진에서 뺐다).

**결과**

| | 조정 전 | 조정 후 |
| --- | --- | --- |
| 카드 지수 (fieldswap, 결투) | 51 ~ 126 | 69 ~ 103 |

| 카드 지수 (fieldswap, 난투장) | 55 ~ 149 | 50 ~ 113 |

난투장에서는 원거리 유닛과 그림자 단검이 여전히 낮다 (견습 궁수 58, 서리 마녀 61, 그림자 단검 50). 원 안을 지키는 데 근접 유닛이 낫기 때문이라, 형식에 따라 좋은 카드가 다른 것으로 두었다.

### 경기 안의 덱 격차 (2026-11-18, 두 번째 조정)

봇 성격을 넣고 보니 한 경기 안에서는 **싼 근접 덱이 너무 셌다** (돌격대장 1:1 82%, 큰손 31%). 카드 한 장씩 잰 전투 지수에는 드러나지 않던 것이다. 완전히 맞추지는 않고 크게 벌어진 원인 둘만 고쳤다.

- **강화한 카드는 별 하나당 비용 +1** (`FIELD_RULES.starCost`). 8라운드까지 덱의 평균 비용이 성격과 상관없이 1.2~1.4이고, 차이는 강화 수였다 (돌격대장 2성 7.5장, 큰손 5.3장). 1등급 카드는 풀에 많고 상점에 자주 떠서 2성이 쉽고, 2성은 비용 그대로 능력치가 ×1.8이라 싼 카드일수록 득이 컸다. 강화 배율(×1.5)이나 레벨업 속도로는 거의 줄지 않았다.
- **공격 강화도 유닛 공격 배율(×0.5)을 따른다.** 전투 함성 +3이 배율 없이 더해져서 공격 0.5인 쥐 떼가 8초 동안 일곱 배가 됐다. 전투 함성을 산 쪽의 승률이 84%였다. 각성의 공격 +2도 같다.
- 그 결과 연금술사의 "융합 카드 비용 −1"이 강화 비용을 지워 주는 셈이 돼서 1:1 71%까지 올랐다. 할인을 빼고 **융합 4회**로 바꿨다. 상인은 약해져서(38%) **골드 +3**으로 올렸다.
- 중간 유닛(창기병·망치 기사·거신)을 키우는 것은 효과가 없어서 되돌렸다. 큰손 덱도 실제로는 비싼 카드를 거의 갖고 있지 않았다 (평균 비용 1.40).

| | 조정 전 | 조정 후 |
| --- | --- | --- |
| 성격별 1:1 승률 | 31 ~ 82% | 38 ~ 58% |
| 성격별 8인 평균 순위 | 2.46 ~ 6.03 | 3.51 ~ 5.38 |
| 지휘관 1:1 승률 (성격 없음, 1,000경기) | 43 ~ 54% | 43 ~ 54% |
| 지휘관 8인 평균 순위 (300경기) | 4.30 ~ 4.68 | 4.15 ~ 4.97 |

## 한 경기

웹의 "한 경기"에서 봇과 처음부터 끝까지 해 볼 수 있다. [engine/game.js](engine/game.js)가 상점·경제·라운드 진행을, [engine/shopbot.js](engine/shopbot.js)가 상점 봇을 맡는다.

1. **사전 선택**: 지휘관 1명과 픽 카드(1:1은 8종, 8인은 5종, 5등급은 1종까지).
2. **시작 덱 드래프트**: 지휘관 고유 카드 1장 + 3장 중 1장 고르기를 7번. 후보의 첫 장은 내 픽에서, 나머지는 공용 풀에서 뜬다 (1등급 60%, 2등급 30%, 3등급 10%).
3. **상점**: 5칸 중 1칸은 시그니처 칸이라 내 픽에서만 뜬다 (첩보원은 2칸). 다음 전투의 형식과 전장이 미리 보인다.
4. **전투**: 1~2라운드는 중립 몬스터와 연습, 그다음은 1:1은 결투, 8인은 로테이션.
5. **결과**: 진 쪽이 HP를 잃는다. 1:1은 HP 40, 8인은 HP 100이 0이 되면 탈락.

- 1:1은 그대로 뒀다 (9라운드, 9분. 목표 10~15분).

- **마나 모으기와 다시 뽑기** (2026-11-18): 2.5초 안에 낼 수 있는 더 좋은 카드가 있으면, 급한 카드가 아닌 한 싼 카드를 내지 않고 마나를 모은다. 다시 뽑기는 쓸 데 없는 카드만 버린다: 10초 안에 최대 마나가 닿지 않는 비싼 카드, 지금 조건이 안 맞는 주문. 예전에는 마나가 모자란 카드까지 버렸다. 예전 봇(`plan: false`)과 맞붙이면 결투 52.9%, 난투장 52.2%, 연합전 54.8%를 이긴다.
- **주문 조건** (2026-11-18): 포고는 이미 싸우고 있는 적 유닛(내 유닛 둘 이상이 칠 수 있는 거리)만 지목한다. 정화는 갑옷을 지우거나 피해 7로 마무리할 때, 각성은 화염술사·거신을 먼저, 교란은 곧 터질 필살기나 쓰러뜨릴 수 있는 유닛을 먼저, 방진은 근접 유닛이 둘 이상일 때 낸다.
- **난투장 1위 견제**: 나보다 점수가 높은 상대 중 1위가 있으면, 화염탄·연쇄 번개·눈보라·교란·포고를 그 상대의 유닛에 먼저 쓴다 (`leaderOf`). 유닛은 원래대로 원으로 간다. 효과는 작다: 2위의 평균 점수가 13.3에서 14.0으로 올랐다 (1위 20.2).
- **첩보원 봇** (2026-11-18): 상점 봇을 첩보원만 맨 뒤에 돌려서, 상대들이 이번 라운드에 고른 시작 카드를 본 뒤에 고른다 (`shopBotOrder`).
  - **빠른 대응 (기본, `spyCounterOpening`)**: 상대가 원거리로 시작하면 암살 유닛, 싼 근접 유닛을 둘 이상 몰아 내면 눈보라·연쇄 번개·폭탄 고블린·가시 거북, 비싼 유닛이면 화염탄·교란·포고, 범위 주문이면 체력이 높은 유닛에 점수를 더해 시작 카드를 고른다. 시간은 거의 들지 않는다. 1:1 1,500경기에서 쓸 때 48.4%, 안 쓸 때 50.4%로 오차 안이다.
  - **미리 돌려 보기 (`spyInfo: true`, `spyOpening`)**: 시작 카드 후보 다섯 가지를 상대의 공개된 덱과 시작 카드로 6판씩 돌려 보고 가장 많이 이긴 것을 고른다. 결투 한 판에서는 49.3% → 52.3%로 오르지만 한 경기 단위로는 1:1 48.1% → 49.0%로 오차 안이고, 시간이 6~7배 든다.
  - 둘 다 효과가 작은 까닭: 시작 카드는 전투 초반에만 영향을 주고, 봇은 늘 같은 규칙으로 시작 카드를 고르므로 정보가 없어도 예측할 수 있다. 상대가 사람이면 정보의 값이 더 클 수 있다.

### 성향별 레이팅 재기

`sim/ranked.mjs`는 경기마다 참가자의 실력·성격·그 경기의 지휘관·상점 성향을 기록하고, 묶음마다 **기대 대비 성적**을 낸다.
- **기대 대비 성적:** 경기 전 레이팅으로 기대한 승점과 실제 승점의 차이를, 상대 한 명씩 견준 평균이다.
- **레이팅 환산:** 기대 대비 성적을 레이팅 차로 바꾼 값이다. 그 묶음이 평균보다 몇 점 센지를 뜻한다.
- 배치 10경기는 빼고 센다. 실력 차가 섞이지 않게 `--level normal`(모두 같은 실력)로 쟀고, 오차는 ±20~40점쯤이다.

| 묶음 | 8인 (160명 × 25경기) | 1:1 (200명 × 40경기) |
| --- | --- | --- |
| 돌격대장 | +50 | +60 |
| 저격수 | +20 | −1 |
| 주문술사 | +2 | −5 |
| 장사꾼 | −18 | +11 |
| 철벽 | −19 | −19 |
| 큰손 | −32 | −57 |
| 군주 (그 경기의 지휘관) | +22 | +21 |
| 첩보원 | +11 | +36 |
| 장군 | +3 | +10 |
| 연금술사 | −2 | −26 |
| 상인 | −24 | −25 |

- 성격 없이 사람마다 주력 지휘관을 하나로 고정한 1:1 리그(`--personas none --commanders main`)에서는 첩보원 +28, 군주 +26, 연금술사 +16, 장군 −18, 상인 −42였다. **상인은 어느 방식으로 재도 가장 낮다.**
- 레이팅 60점 차이는 평균 상대를 이길 확률 58%쯤이다. 성향 차이는 실력 차(입문과 어려움 사이 400점 넘게)보다 훨씬 작다.
- 상점 성향 표도 나오지만, 지금은 성격이 성향을 정해서(소비형은 돌격대장뿐) 성격과 겹친다. 성향만 따로 보려면 성격 없이 돌려야 한다.
- 결과는 `sim/out/ranked_<모드>_groups.csv`에도 저장된다.

### 난투장 처치 점수를 정한 과정 (2026-11-16)

처치 점수가 없을 때는 원 안에 들어가는 유닛 **수**만 세서, 싼 근접 유닛이 난투장에서 너무 셌다 (근접 유닛 0~1장인 덱 지수 34, 6장 이상 166). 난투장 2,000판씩 비교했다.

| 처치 점수 | 목표 | 길이 중앙값 | 점수 중 처치 비중 | 근접 0~1장 / 6장 이상 |
| --- | --- | --- | --- | --- |
| 없음 | 15 | 40초 | 0% | 33 / 169 |
| 마나 비용 × 0.4, 원 안 ×2 | 20 | 33초 | 61% | 89 / 144 |
| 마나 비용 × 1, 원 안 ×2 | 15 | 15초 | 77% | 143 / 100 |
| **한 기에 1점, 원 안 ×2** | **20** | **30초** | **65%** | **94 / 123** |

- 크게 주면 판이 빨리 끝나고 원거리·주문 덱이 거꾸로 너무 세진다.
- 마나 비용으로 매기면 싼 유닛은 잡아도 점수가 적어서, 싼 유닛을 원에 쏟아붓는 쪽이 여전히 유리하다.
- `killScore`, `killZoneMult`, `killPerMana`, `captureGoal`로 바꿔 볼 수 있다.

## 남은 문제

- **몸(유닛)이 아닌 카드는 여전히 조금 약하다.** 주문·강화는 대부분 70~90, 싼 유닛은 85~105. 결투·연합전은 유닛이 하나라도 있으면 본진을 못 치는 규칙이라 몸 수가 중요하다. 방진(70~78)이 가장 낮다.
- **난투장에서는 원거리 유닛과 그림자 단검이 낮다** (50~61). 형식에 따라 좋은 카드가 다른 것으로 두었다.
- **전투 한 판에서는 군주가 약하다** (지수 72~73). 군주 패시브(HP 피해 감소)가 한 경기에서만 의미가 있어서다. 한 경기에서는 다른 지휘관과 비슷하다.
- **8인에서는 돌격대장 봇이 아직 앞선다** (평균 순위 3.51, 큰손 5.38. 랭크전 레이팅 환산 +50 / −32). 2성 비용 +1과 공격 강화 배율로 크게 줄였지만 완전히 맞추지는 않았다.
- **상인이 랭크전에서 가장 낮다** (레이팅 환산 −24 ~ −42).
- **랭크 티어가 실력을 다 가르지 못한다.** 같은 실력도 레이팅이 400점쯤 흩어진다. 경기의 운을 줄이거나 시즌을 길게 봐야 한다.
- **첩보원의 정보 패시브는 봇에게 거의 쓸모가 없다.** 봇이 정보로 시작 카드를 고르게 했지만 경기 결과는 오차 안에서만 달라졌다. 상대가 사람이면 시작 카드를 예측하기 어려워서 정보의 값이 더 클 수 있다.
- **난투장과 연합전은 대난투만큼 혼잡하지 않다** (필드 유닛 최대 10기). 대난투의 분대 소환을 다른 형식에도 쓸지는 정하지 않았다.
- **대난투의 공동 1위가 많다.** 시간이 다 됐을 때 지휘관 체력이 꽉 찬 사람이 둘 이상인 판이 절반쯤이다. 대난투는 아직 정식 모드가 아니라 나중에 본다.
- 1위 견제는 주문만 바꾼다. 유닛의 움직임이나 배치는 앞서는 사람을 보지 않는다.
- 8인 경기는 14라운드, 15분이다 (기획서 약 15라운드, 20~25분). 끝날 때 상점 레벨이 5.9라 레벨 7~8 보상은 거의 쓰이지 않는다. 1:1(9분)은 목표(10~15분)보다 조금 짧다.
- 키보드로는 내 배치 칸만 고를 수 있다. 유닛은 마우스로 고른다.

## 키보드 단축키 (웹)

글자 키는 자판의 자리로 읽어서, 한글 입력 상태에서도 그대로 동작한다.

| 화면 | 키 | 하는 일 |
| --- | --- | --- |
| 전투 | `1`~`7` | 손패 카드 고르기 (표적이 필요 없으면 바로 낸다) |
| | `Q` `W` `E` `R` `T` | 내 배치 칸 앞줄 1~5 |
| | `A` `S` `D` `F` `G` | 내 배치 칸 가운뎃줄 |
| | `Z` `X` `C` `V` `B` | 내 배치 칸 뒷줄 (본진 앞) |
| | `` ` `` | 다시 뽑기 (누른 뒤 버릴 카드 번호) |
| | `Esc` | 선택 취소 |
| | `Space`, `-` `=` | 일시정지, 느리게·빠르게 |
| 상점 | `1`~`5` | 카드 사기. 보스 보상이 있으면 보상 고르기 (`0`은 받지 않기) |
| | `D` `F` `S` | 리롤, 경험치 구매, 잠금 |
| | `←` `→` | 내 덱에서 카드 고르기 |
| | `G` `X` `V` `C` | 시작 카드 지정, 덱에서 빼기, 융합(몸체 → 재료 고르고 다시 `V`), 3장 합치기 |
| | `Enter` | 전투 시작 |
| 드래프트 | `1`~`3` | 후보 고르기 |
| 결과 창 | `Enter` | 첫 버튼 (다음 라운드 등) |

유닛(적이든 내 것이든)은 마우스로 눌러서 고른다. 포고로 지목된 유닛은 금색 점선 테두리가 생긴다.
