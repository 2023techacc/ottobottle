# 카드 오토배틀러 (가제)

기획서의 **1:1 경기와 8인 경기**(사전 선택 → 상점과 전투 반복)를 옮긴 규칙 엔진, 봇, 대량 시뮬레이터, 그리고 브라우저 플레이 화면이다.
전투는 **유닛 소환 전투**다: 덱·손패·마나로 카드를 내면 유닛이 필드에 소환돼 걸어가서 사거리 안의 적을 친다.
의존성이 없고 빌드도 없다. Node 20 이상이면 된다.

```
engine/   규칙만 담은 순수 코드 (Node와 브라우저가 같은 파일을 쓴다)
            field.js 전투, fieldbot.js 전투 봇, game.js 상점·경기, shopbot.js 상점 봇, cards.js 카드 데이터
sim/      봇 대 봇 대량 시뮬레이션, 결과는 sim/out/*.csv (git에는 올리지 않는다. 다시 돌리면 똑같이 나온다)
web/      봇과 직접 붙어 보는 플레이 화면 (GitHub Pages에 그대로 올릴 수 있다)
test/     엔진 테스트
tools/    로컬 확인용 정적 서버
```

## 실행

| 하려는 것 | 명령 |
| --- | --- |
| 테스트 | `npm test` |
| 플레이 화면 | `npm run web` 후 http://localhost:4173/web/ ("한 경기"와 "전투 한 판") |
| 형식별 전투 비교 (결투·난투장·연합전) | `npm run sim` (= `node sim/field.mjs --format all`) |
| 한 형식만 | `node sim/field.mjs --format melee4 --games 4000` |
| 대난투 | `node sim/field.mjs --format ffa --players 8 --games 200` (한 판에 1초쯤) |
| 카드 넣어 보기 | `node sim/fieldswap.mjs` |
| 한 경기 (1:1 / 8인) | `node sim/match.mjs` / `node sim/match.mjs --mode rank8` |
| 규칙 수치를 바꿔서 | `node sim/field.mjs --rules "{\"commanderHp\":30}"`, `node sim/match.mjs --econ "{\"playerHp\":60}"` |

전투 수치는 [engine/rules.js](engine/rules.js)의 `DEFAULT_RULES`(마나·뽑기 등 공통) 위에 [engine/field.js](engine/field.js)의 `FIELD_RULES`를 덮어쓴다. 경제 수치는 [engine/game.js](engine/game.js)의 `DEFAULT_ECON`이다.

GitHub Pages에는 저장소 루트를 그대로 올리면 된다. 루트의 `index.html`이 `web/`으로 넘겨 준다.

## 전투

### 기본 규칙

| 항목 | 내용 |
| --- | --- |
| 자원 | 마나 3에서 시작, 1.5초마다 1, 최대치는 8초마다 +1 (8까지). 손패 4장으로 시작, 3초마다 1장, 7장까지. 다시 뽑기는 마나 1, 쿨다운 4초 |
| 필드 | 칸이 없는 연속 좌표. 배치 칸 한 변이 2 |
| 배치 칸 | 칸은 소환할 때만 쓴다. 각자 본진 앞에 가로 5 × 세로 3칸이 있고, **내 칸에만** 놓을 수 있다 |
| 소환 | 한 사람당 8기까지. 가득 차면 내 유닛 하나를 대체한다 |
| 이동 | 표적 쪽으로 속도만큼 부드럽게 걷고, 사거리 안에 들면 멈춰서 친다. 유닛끼리는 겹치지 않고 서로 밀어낸다 |
| 표적 | 가장 가까운 적. 치고 있던 적이 사거리 안에 있으면 계속 친다. 거리가 같으면 시계 방향으로 가까운 상대 |
| 본진 | **지나치기 없음**: 상대 팀 유닛이 하나라도 살아 있으면 본진을 칠 수 없다 (대난투만 다르다). 지휘관이 쓰러지면 그 사람의 유닛이 모두 사라진다 |
| 시간 | 40초. 30초부터 1초마다 공격 +10% (과열). 시간이 다 되면 지휘관 체력 비율로 판정 |
| 수치 | 지휘관 체력 40, 유닛 공격 ×0.5, 유닛 체력 ×1.25 (결투가 30초쯤 되게만 맞췄다) |

전열·후열 대신 **근접·원거리**로 나눈다: 전투 함성·장군 패시브·성채는 근접 유닛에, 방진·안개는 원거리 유닛에 적용한다. 좁은 협곡은 배치 칸의 양쪽 끝 세로줄을 막는다.

### 형식

| 형식 | 인원 | 필드 | 이기는 법 |
| --- | --- | --- | --- |
| 결투 | 2 | 10×12 | 상대 본진을 부순다 |
| 연합전 | 4 (2:2) | 20×12 | 상대 팀 본진 둘을 모두 부순다 |
| 난투장 | 4 | 반지름 10인 원 | **중앙 점령**: 점수로 순위 (아래) |
| 보스 레이드 | 1 + 보스 | 10×12 | 40초 동안 보스에게 준 피해 |
| 대난투 | 3~12 | 반지름 "4 + 인원 × 1.7"인 원 | 마지막까지 지휘관이 남는다 (아래) |

**난투장**은 본진을 치지 않는다. 한가운데 반지름 3인 원 안에 유닛이 **가장 많은 한 사람**만 1초에 1점(같으면 아무도 못 얻는다), 적 유닛을 쓰러뜨리면 1점(**원 안에서면 2점**, 작은 복제는 절반, 같은 순간에 함께 쓰러뜨리면 나눠 갖는다).
20점에 먼저 닿으면 바로 끝나고, 아니면 40초에 점수순으로 1~4위. 유닛은 거리 4.5 안의 적만 상대하고, 상대할 적이 없으면 원 안쪽으로 들어가 버틴다.

**보스 레이드**: 고대 골렘은 위쪽 가운데에 서 있고 움직이지도 밀리지도 않는다. 쓰러지지 않고, 10초마다 전조 1.5초 뒤 자기 주변(반지름 3.8)을 친다. 지휘관은 피해를 받지 않는다.

### 대난투 (2026-11-17)

여럿이 한 필드에서 그냥 싸우는 모드다. "전투 한 판"에서 3~12명으로 해 볼 수 있다 (8인 경기 로테이션에는 넣지 않았다).

| 항목 | 내용 (`FFA_RULES`) |
| --- | --- |
| 필드 | 반지름 4 + 인원 × 1.7 (8명이면 17.6). 이웃의 배치 칸끼리 겹치지 않는 가장 작은 크기 |
| **분대** | 유닛 카드 한 장에 같은 유닛이 **3기** 나온다. 카드는 한 장만 버린 더미로 돌아간다. 한 사람당 16기까지 |
| 자원 | 시작 마나 5, 1초마다 마나 1, 1.5초마다 1장 |
| 유닛 체력 | ×2.5 (다른 형식은 ×1.25) |
| 본진 | 가까이(4 안) 있는 자기 유닛만 지킨다. 싸우러 나간 사이에 털릴 수 있고, 본진이 받는 피해는 ×2 |
| 시간 | 75초 (과열은 55초부터). 순위는 먼저 쓰러진 순서, 시간이 다 되면 지휘관 체력 비율 |

**왜 이렇게 됐나** (8명, 봇끼리 24~120판씩). 처음에는 다른 형식과 같은 규칙으로 돌렸는데 혼잡하지 않았다.

| 바꾼 것 | 필드 유닛 평균 / 최대 | 탈락 인원 | 한 명만 남은 판 |
| --- | --- | --- | --- |
| 다른 형식과 같은 규칙 | 12.6 / 19 | 1.9 | 0% |
| 유닛 체력 ×2.5, 마나 1초, 뽑기 1.5초, 본진 지키는 범위 6 | 21.4 / 30 | 2.1 | 0% |
| 뽑기 1초, 체력 ×4, 마나 0.7초 | 27.4 / 36 | 1.2 | 0% |
| **위 + 분대 3기, 16기까지** | **54 / 83** | 2.9 | 4% |
| **+ 본진 지키는 범위 6 → 4, 본진 피해 ×2, 75초 (지금)** | **45 / 78** | **5.4** | **18%** |

- 카드가 들어오는 속도를 올려도 유닛이 죽는 속도가 비슷하게 따라 올라서, 한 사람이 동시에 세우는 유닛은 3~4기에서 잘 안 늘었다. **분대 소환**이 가장 크게 들었다.
- 처음 규칙(지나치기 없음)에서는 유닛이 하나라도 있으면 본진을 못 쳐서 아무도 탈락하지 않았다.
- 싸움은 가운데가 아니라 이웃끼리 둘레를 따라 벌어진다. 자리별 승률은 오차 범위 안이다 (9.0~15.6%, 기대 12.5%, 오차 ±6).
- 시간이 다 돼서 끝나는 판이 82%고, 그중 절반쯤은 지휘관 체력이 꽉 찬 사람이 둘 이상이라 1위가 공동이다.

### 같은 순간에 일어난 일에는 순서가 없다

네 사람이 똑같은 덱·똑같은 판단으로 싸우면 전원 동점이 나와야 한다 (테스트로 확인한다).

- 한 틱 안의 공격·필살기·유언 폭발: 그 사이에 체력이 바닥난 유닛도 모두 처리될 때까지는 서 있는 것으로 친다.
- 같은 틱에 낸 주문은 `applyActions`로 함께 처리한다.
- 유닛 밀어내기와 넉백은 모두 같은 순간의 위치를 보고 한꺼번에 옮긴다.
- 거리나 체력이 똑같을 때는 시계 방향으로 가까운 상대가 먼저다.

### 카드

기획서 예시 20종과 지휘관 고유 카드 4종에, 2026-11-17에 5종을 더했다 (공용 풀 27종). 사거리·속도·몸집은 [engine/field.js](engine/field.js)의 `FIELD_STATS`에 있다.

| 카드 | 등급 / 마나 | 효과 |
| --- | --- | --- |
| 가시 거북 | 2 / 3 | 근접 탱커. ◆가시: 근접 공격을 받을 때마다 공격자에게 피해 1 |
| 깃발병 | 2 / 2 | ◆집결: 가까이(1.7 안) 있는 아군 1기당 공격 +1 |
| 폭탄 고블린 | 2 / 2 | 유언: 쓰러질 때 주변(반지름 2)의 적 모두에게 피해 4. 그 폭발로 쓰러진 유닛도 이어서 처리된다 |
| 망치 기사 | 3 / 4 | 넉백: 친 대상을 1.5만큼 밀어낸다 (거신은 절반, 보스는 밀리지 않는다) |
| 눈보라 | 2 / 3 | 적 유닛 하나와 그 주변(반지름 2.2)의 적 모두에게 피해 4, 감속 |

가시와 집결은 엔진에 있었지만 그 효과를 가진 카드가 없었다. 두 수치(가시 피해 2, 집결 +2)는 이제 유닛 공격 배율(×0.5)을 따른다.

**지휘관 고유 카드 둘을 고쳤다** (2026-11-17).

- **포고**(군주): "적 유닛 하나를 6초 동안 지목한다. 내 유닛 전체가 거리와 상관없이 그 유닛부터 노리고, 그 유닛이 받는 피해 +25%." 예전 효과(난전에서 내 칸 하나의 표적 방향을 바꾼다)는 칸 전투용이라 유닛 전투에서 낼 수 없었다. 이제 어느 형식에서나 쓸 수 있다.
- **투자**(상인): 효과는 그대로(이기면, 난투장은 1위면 골드 +3)인데, 봇이 경기에서 한 번도 내지 않고 있었다. 한 경기 안의 전투(`stakes`)에서는 봇이 일찍 낸다. 전투 한 판에서는 아무 효과가 없으므로 내지 않는다.
- 봇끼리 8인 경기 30판: 투자를 낸 판이 상인 전투의 83% (예전 0%), 포고를 낸 판이 군주 전투의 34%.

## 한 경기

웹의 "한 경기"에서 봇과 처음부터 끝까지 해 볼 수 있다. [engine/game.js](engine/game.js)가 상점·경제·라운드 진행을, [engine/shopbot.js](engine/shopbot.js)가 상점 봇을 맡는다.

1. **사전 선택**: 지휘관 1명과 픽 카드(1:1은 8종, 8인은 5종, 5등급은 1종까지).
2. **시작 덱 드래프트**: 지휘관 고유 카드 1장 + 3장 중 1장 고르기를 7번. 후보의 첫 장은 내 픽에서, 나머지는 공용 풀에서 뜬다 (1등급 60%, 2등급 30%, 3등급 10%).
3. **상점**: 5칸 중 1칸은 시그니처 칸이라 내 픽에서만 뜬다 (첩보원은 2칸). 다음 전투의 형식과 전장이 미리 보인다.
4. **전투**: 1~2라운드는 중립 몬스터와 연습, 그다음은 1:1은 결투, 8인은 로테이션.
5. **결과**: 진 쪽이 HP를 잃는다. 1:1은 HP 40, 8인은 HP 100이 0이 되면 탈락.

### 기획서 그대로인 것

| 항목 | 값 |
| --- | --- |
| 수입 | 기본 5, 이자 10골드당 1(최대 3), 연승·연패 2회 +1 / 4회 +2 |
| 지출 | 카드 가격 = 등급, 리롤 2, 잠금 무료, 카드 빼기 2(라운드당 1번), 경험치 4골드에 4 |
| 덱 | 최소 8장, 최대 30장 |
| 등급 확률 | 상점 레벨 3~8 표 그대로 |
| 풀 장수 | 등급별 12/10/8/6/4장, 고른 사람 한 명당 +50% |
| 강화 | 같은 카드 3장 → 2성(공격·체력 ×1.8, 주문 효과 ×1.5), 2성 3장 → 3성 |
| 융합 | 경기당 3회(연금술사 5회), 한 카드에 ◆효과 1개 |
| 8인 로테이션 | 1~2 연습, 3·4·6·8·11·13 결투, 5·10·12·14 난투장, 7 연합전, 9 보스 레이드. 15라운드부터 결투와 난투장을 번갈아. 3명이 남으면 매 라운드 결투(한 명은 유령과), 2명이면 결투 |
| 피해 | 결투: 기본 피해 + 이긴 쪽에 남은 유닛 수. 난투장: 순위별 0 / 30 / 70 / 100%. 연합전: 진 팀 둘이 각자 절반 |
| 보스 보상 | 준 피해 상위 25%는 카드 4장 중 1장 + 5골드, 다음 37.5%는 3장 중 1장, 나머지는 2골드 |
| 유령 | 인원이 모자라면 탈락자의 마지막 덱(없으면 다른 조의 플레이어)을 복제해 채운다. 유령은 피해를 받지 않는다 |

### 기획서에 없어서 정한 것

| 항목 | 정한 내용 |
| --- | --- |
| 상점 레벨 보상 | **고르는 시작 카드 장수**만 는다 (레벨 3~8에 1·1·2·2·3·3장). 시작 손패 4장 중 그만큼을 덱에서 직접 고른다 |
| 레벨업 경험치 | 3→4는 6, 4→5는 10, 5→6은 16, 6→7은 24, 7→8은 36. 라운드마다 +2 |
| 기본 피해 | 두 라운드마다 +1 (3·4라운드 2 … 15라운드부터 8). 무승부는 양쪽이 절반(올림) |
| 남은 유닛 수 | 전투가 끝날 때 필드에 남은 유닛을 센다 (작은 복제 포함) |
| 군주 패시브 | 난전(난투장)에서 받는 HP 피해 −30% |
| 첩보원 패시브 | 상대가 고른 시작 카드를 미리 본다 (상점의 상대 정보와 전투 기록에 나온다) |
| 중립 카드 | 기획서의 "기본 중립 카드 20종"이 따로 없어서, 지휘관 고유 카드를 뺀 카드 전체가 풀에 들어간다 |
| 시작 덱의 고유 카드 | 풀에서 온 카드가 아니라서, 빼도 풀로 돌아가지 않는다 |
| 잠금 | 한 라운드만 유지된다 |
| 연습 라운드 | 중립 몬스터는 싼 유닛 8장을 느리게 내는 봇이다 |
| 난전의 연승·연패 | 1위는 승, 꼴찌는 패, 가운데 순위는 연속 기록을 바꾸지 않는다 |
| 탈락 | 카드는 풀로 돌아간다. 같은 라운드에 여럿이 탈락하면 HP가 더 많이 남은 쪽이 순위가 높다 |
| 조 편성 | 살아 있는 플레이어를 매 라운드 무작위로 섞는다 |

## 봇

- **전투 봇** ([engine/fieldbot.js](engine/fieldbot.js)): 손패와 공개 정보만 보고 카드마다 점수를 매겨 고른다. 반응 지연과 실수 확률로 난이도를 나눈다 (쉬움·보통·어려움).
- **난투장 1위 견제**: 나보다 점수가 높은 상대 중 1위가 있으면, 화염탄·연쇄 번개·눈보라·교란·포고를 그 상대의 유닛에 먼저 쓴다 (`leaderOf`). 유닛은 원래대로 원으로 간다. 효과는 작다: 2위의 평균 점수가 13.3에서 14.0으로 올랐다 (1위 20.2).
- **상점 봇** ([engine/shopbot.js](engine/shopbot.js)): 카드 가치 점수(임시값)로 사고, 저축형·균형형·소비형 성향이 있다.

### 난투장 처치 점수를 정한 과정 (2026-11-16)

처치 점수가 없을 때는 원 안에 들어가는 유닛 **수**만 세서, 싼 근접 유닛이 난투장에서 너무 셌다 (근접 유닛 0~1장인 덱 지수 34, 6장 이상 166). 난투장 2,000판씩 비교했다.

| 처치 점수 | 목표 | 길이 중앙값 | 점수 중 처치 비중 | 근접 0~1장 / 6장 이상 |
| --- | --- | --- | --- | --- |
| 없음 | 15 | 40초 | 0% | 33 / 169 |
| 마나 비용 × 0.4, 원 안 ×2 | 20 | 33초 | 61% | 89 / 144 |
| 마나 비용 × 1, 원 안 ×2 | 15 | 15초 | 77% | 143 / 100 |
| **한 기에 1점, 원 안 ×2** | **20** | **30초** | **65%** | **94 / 123** |

- 크게 주면 판이 빨리 끝나고 원거리·주문 덱이 거꾸로 너무 세진다.
- 마나 비용으로 매기면 싼 유닛은 잡아도 점수가 적어서, 싼 유닛을 원에 쏟아붓는 쪽이 여전히 유리하다.
- `killScore`, `killZoneMult`, `killPerMana`, `captureGoal`로 바꿔 볼 수 있다.

## 남은 문제

- **지휘관 차이**: 군주가 가장 약하다 (결투 65, 난투장 55). 포고를 낼 수 있게 됐지만 봇은 군주 전투의 34%에서만 낸다. 첩보원은 난투장에서 약하다 (60, 그림자 단검이 원 밖으로 나간다). 장군·연금술사는 난투장에서 세다 (142·137). 지휘관 고정 시작 덱 기준이라 드래프트를 거치는 실제 경기에서는 덜 벌어진다 (8인 1위 비율 7.2~17.6%).
- **1마나 유닛과 가시 거북이 좋다.** 비용 곡선 문제로 보인다.
- **난투장과 연합전은 대난투만큼 혼잡하지 않다** (필드 유닛 최대 10기). 대난투의 분대 소환을 다른 형식에도 쓸지는 정하지 않았다.
- **대난투의 공동 1위가 많다.** 시간이 다 됐을 때 지휘관 체력이 꽉 찬 사람이 둘 이상인 판이 절반쯤이다. 남은 유닛 수 같은 두 번째 기준이 필요할 수 있다.
- 1위 견제는 주문만 바꾼다. 유닛의 움직임이나 배치는 앞서는 사람을 보지 않는다.
- 8인 경기가 기획서 목표(약 15라운드, 20~25분)의 두 배쯤 길다 (28라운드, 30분).
- 키보드로는 내 배치 칸만 고를 수 있다. 유닛은 마우스로 고른다.

## 키보드 단축키 (웹)

글자 키는 자판의 자리로 읽어서, 한글 입력 상태에서도 그대로 동작한다.

| 화면 | 키 | 하는 일 |
| --- | --- | --- |
| 전투 | `1`~`7` | 손패 카드 고르기 (표적이 필요 없으면 바로 낸다) |
| | `Q` `W` `E` `R` `T` | 내 배치 칸 앞줄 1~5 |
| | `A` `S` `D` `F` `G` | 내 배치 칸 가운뎃줄 |
| | `Z` `X` `C` `V` `B` | 내 배치 칸 뒷줄 (본진 앞) |
| | `` ` `` | 다시 뽑기 (누른 뒤 버릴 카드 번호) |
| | `Esc` | 선택 취소 |
| | `Space`, `-` `=` | 일시정지, 느리게·빠르게 |
| 상점 | `1`~`5` | 카드 사기. 보스 보상이 있으면 보상 고르기 (`0`은 받지 않기) |
| | `D` `F` `S` | 리롤, 경험치 구매, 잠금 |
| | `←` `→` | 내 덱에서 카드 고르기 |
| | `G` `X` `V` `C` | 시작 카드 지정, 덱에서 빼기, 융합(몸체 → 재료 고르고 다시 `V`), 3장 합치기 |
| | `Enter` | 전투 시작 |
| 드래프트 | `1`~`3` | 후보 고르기 |
| 결과 창 | `Enter` | 첫 버튼 (다음 라운드 등) |

유닛(적이든 내 것이든)은 마우스로 눌러서 고른다. 포고로 지목된 유닛은 금색 점선 테두리가 생긴다.
